# 🏎️ Supercars Olivos

Proyecto web desarrollado con **HTML, CSS y JavaScript** para presentar un catálogo de vehículos deportivos y superdeportivos.

🌐 **Página web:** [Supercars Olivos](https://agusgrandon.github.io/Supercars-Olivos/)

---

# 📌 Descripción

**Supercars Olivos** es una página web diseñada para presentar vehículos deportivos y superdeportivos mediante un catálogo visual.

El sitio organiza los vehículos en dos categorías principales:

- Superdeportivos / Premiums.
- Deportivos / Nobles.

Cada sección presenta los modelos mediante imágenes y permite acceder a la opción de cotización. Además, el sitio cuenta con una sección de contacto destinada a quienes desean realizar consultas sobre los vehículos.

---

# 🛠 Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** estilos visuales, distribución de los elementos y diseño responsive.
- **JavaScript:** generación dinámica de las tarjetas de vehículos mediante la creación e inserción de elementos HTML desde código JavaScript.
- **Git y GitHub:** control de versiones y alojamiento del proyecto.
- **GitHub Pages:** publicación de la página web.
